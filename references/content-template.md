# 中文运营文案模板

## 标题原则

标题要像真人写，突出结果或场景，不要只有产品名。

可用结构：

- `8个初中英语单词同音记忆动画`
- `像看动画一样背单词，孩子更容易记住`
- `把抽象英语单词变成小故事`
- `这组英语单词，用谐音+画面一起记`

## 正文结构

推荐 4 段：

1. 一句话说明内容是什么。
2. 列出视频覆盖的单词/知识点。
3. 说明适合谁、解决什么问题。
4. 轻引流：有课文、词汇表、讲义想做成视频，可私信。

示例：

```text
这一版是 8 个 10 秒初中英语词汇同音记忆动画合集。

Vegetable 蔬菜：歪着剥
Treasure 宝藏：揣着
Holiday 假期：好累得
Favorite 最喜欢的：飞我瑞特
Remember 记得：人们背
Neighbor 邻居：那一波
Healthy 健康的：喝了西
Season 季节：洗森

把抽象单词变成小故事，先记画面，再记发音，适合英语启蒙、初中词汇复习、课堂导入和短视频英语素材。

如果你有课文、词汇表、绘本或讲义，想做成这种动画教学视频，可以私信我。
```

## 标签池

英语教学类：

```text
英语学习,初中英语,英语单词,单词记忆,英语启蒙,儿童英语,AI教学,趣味英语,绘本英语,动画课
```

产品/获客类：

```text
哇学社,特立达叙影,AI视频,AI教育,教学视频,课件制作,英语老师,教培机构
```

## 平台差异

- 抖音：正文可短，标签更重要。
- 快手：标题/正文可以更口语。
- 视频号：正文不要太长，突出“适合家长/老师”。
- B站：标题明确、简介可详细，分区可默认 `208`。
- 小红书：更适合痛点式标题和图文/短视频，但当前发布自动化不稳定。
